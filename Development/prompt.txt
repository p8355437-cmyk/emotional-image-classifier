I want to build an app where a user can upload a picture. That picture will be processed by an azure machine learning endpoint. The endpoint details can be found in the README.md file in the Development folder. Create the app following the architecture document titled 'technical_architecture.md' in the Development folder. Additional notes:
- Don't use any fancy ui framework. Vanilla javascript is the go to here but make it look modern and minimalist
- When a picture is uploaded show a preview so the user can see what they uploaded
- When you create the backend create it in the same folder as the frontend so when we load the resources they are in the same folder
- The response you receive from the azure endpoint is a json string so parse it using JSON.parse
